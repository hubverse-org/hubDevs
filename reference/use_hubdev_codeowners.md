# Hubverse Developer CODEOWNERS setup

Creates the hubverse package CODEOWNERS file at `.github/CODEOWNERS`.

## Usage

``` r
use_hubdev_codeowners()
```

## Details

The file requires a review from the `hubverse-org/hubverse-developers`
team for changes to the package's GitHub Actions workflows and to the
CODEOWNERS file itself. GitHub enforces the review only where the
default branch is protected by a rule that requires review from code
owners.
